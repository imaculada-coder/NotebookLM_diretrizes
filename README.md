# NotebookLM_diretrizes
Diretrizes de comandos executados em um NotebookLM como apoio na construção de um estudo econômico sobre as negociações de dívidas do FIES.

Resultado da pesquisa disponível no notebook via link: https://notebook.google.com/notebook/0257e46c-fa7d-443b-8716-c3c7c2274253

Objetivo:

Avaliar o efeito causal da implementação do programa Desenrola Fies sobre a taxa de transição para a inadimplência entre estudantes originalmente adimplentes ("bons pagadores"), investigando a possível ocorrência de risco moral (moral hazard) decorrente da assimetria de incentivos entre estudantes adimplentes e inadimplentes, bem como mensurar o impacto fiscal associado à eventual frustração das receitas projetadas para a União.
